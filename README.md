# ChatGPT Images Preset Archive

A searchable archive of ChatGPT Images presets, rotating prompts, seasonal ideas, and Images 2.5 templates from 2025 - 2026.

## Live Website

https://byarahman.github.io/chatgpt-images-preset-archive/

## Features

- 73 verified archive entries
- Searchable preset library
- Category filtering
- Evidence filtering
- Grid and table views
- Responsive desktop and mobile experience
- Light and dark mode
- Source links for verification
- GitHub Pages deployment

## Categories

- Current Images 2.5
- Images 2.5 Templates
- Earlier Rotation
- Seasonal / Event
- Launch Era

## Evidence Model

- A - Official OpenAI
- B - First-party ChatGPT
- C 0 Historical first-party

## Purpose

This project preserves a structured snapshot of ChatGPT Images inspiration cards, prompts, production templates, and historical rotations.

The archive does not claim to capture every region-specific experiment, A/B test, or short-lived prompt variation.
